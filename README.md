# TherapeuticsBench Antibody Discovery (TxBench-Ab)
TxBench-Ab is a verifiable benchmark for antibody discovery and the second focused slice of a broader benchmarking effort across drug-discovery stages and therapeutic modalities, after TxBench-PP. 

## Current Release

- `evals/`: seven public example evaluations with prompt/config metadata.
- `trajectories/`: public trajectories for selected model-harness configurations for the public evaluations.
