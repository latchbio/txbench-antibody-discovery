# TherapeuticsBench Antibody Discovery (TxBench-Ab)
TxBench-Ab is a verifiable benchmark for antibody discovery and the second focused slice of a broader benchmarking effort across drug-discovery stages and therapeutic modalities, after TxBench-PP. The benchmark consists of 100 experimentally grounded evaluations spanning ten competencies in therapeutic antibody discovery, from target assessment and assay design to cellular pharmacology, antibody engineering, and candidate de-risking.

## Current Release

- `evals/`: seven public example evaluations with prompt/config metadata.
- `trajectories/`: public trajectories for selected model-harness configurations for the public evaluations.
